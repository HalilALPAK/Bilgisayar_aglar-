# Technical Report Structure: UDP Reliable File Transfer Protocol

This document provides a structure and key content for your 8-12 page technical report as required by the project specifications.

## 1. Introduction (Giriş)
- **Objective**: Implement a reliable file transfer protocol on top of UDP.
- **Context**: Computer Networks Term Project, Bursa Technical University.
- **Scope**: Stop-and-Wait vs. Go-Back-N (GBN) mechanisms, error simulation, and performance analysis.

## 2. Problem Definition (Problem Tanımı)
- Explain why UDP is unreliable (no ACKs, no retransmission, no order).
- Describe the need for reliability in file transfers.
- Define the constraints: artificial packet loss, limited buffer sizes, etc.

## 3. System Architecture (Sistem Mimarisi)
- **Client-Server Model**: Describe how the client initiates the transfer and the server listens.
- **Component Diagram**:
    - `Packet Layer`: Handles serialization and checksums.
    - `Transfer Layer`: Implements Stop-and-Wait and GBN.
    - `Logging Layer`: Records metrics for analysis.

## 4. Protocol Design (Protokol Tasarımı)
- **Packet Structure**: Detail the header fields.
    - `Type`: START, DATA, ACK, END.
    - `SeqNum`: For ordering and duplicate detection.
    - `Checksum`: MD5 hash for data integrity.
- **State Machine**:
    - Describe the sequence of events (Handshake -> Data -> Closing).
    - Explain how Timeouts are handled.

- Define:

    - **Goodput**: Useful data rate (excluding retransmissions).
